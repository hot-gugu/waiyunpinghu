# waiyunpinghu

## 首页及发布

默认入口为 index.html，自动进入 AI报警中心（AI隐患核查.html）。监测一张图通过后台菜单进入，点击平台标题返回AI报警中心。

所有资源均按仓库内相对路径引用，适用于 GitHub Pages 的仓库子路径。必须将 assets 整个目录及“流程图和上报字段”目录一同提交，不能只上传根目录 HTML／JS。

在仓库 Settings → Pages 中选择用于发布的分支及根目录，发布完成后使用 Pages 提供的网站地址访问；GitHub 仓库文件预览不是网站运行页面。本仓库使用 .nojekyll 按静态文件发布。

本地使用“启动原型服务.cmd”可打开AI报警中心。短信、身份认证及消防管家接口仍属于未接入的正式服务；GitHub Pages仅运行静态演示，不运行Python标注写回服务。
