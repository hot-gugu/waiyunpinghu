原型标注文件替换与同步

支持的数据文件：原型标注.md、原型标注数据.js、原型手工标记.json。

1. 从其他地方修改完成后，将对应文件替换至本仓库根目录。
2. 直接双击 HTML 预览：双击“同步原型标注.cmd”，成功后刷新页面，再打开标注。
   仅替换原型标注数据.js 时，也可直接点击标注面板的“重新载入标注”。
3. 使用 prototype-local-server.py 本地服务预览：替换文件后重新打开标注或刷新，服务会读取变更并同步各份成果。
4. GitHub Pages：发布同步后的文件；刷新或点击“重新载入标注”可重新读取 JS、MD 和 JSON。网页无法直接写入 GitHub。
5. 不方便运行同步工具时，可点击“导入更新文件”，选择 JSON、JS 或 MD；该方式先更新当前浏览器，不冒充已写回仓库。

同步规则：按 ID 合并，保留人工新增、定位点和 deleted 删除标记。时间统一按实际时间比较；相同时间的冲突按文件修改先后合并。请给真正修改的记录更新 updatedAt（ISO 日期含时区），避免较早内容覆盖新内容。删除请设置 deleted:true，不要仅移除数组项。
JS 格式须为 window.PROTOTYPE_ANNOTATIONS = [合法 JSON 数组];，不执行导入文件中的任意脚本。
格式错误会停止同步并保留现有生成文件。
同步输出：原型标注.md、原型标注数据.js、原型手工标记.json、原型标注.HTML、原型手工标记文件包.zip。
HTML 阅读版保留已有截图；字段文字自动同步，截图不会自动重拍。
